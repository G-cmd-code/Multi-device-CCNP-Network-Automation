# Multi-device-CCNP-Network-Automation
Python/Netmiko automation scripts for a GNS3-based CCNP lab — pushes OSPF/EIGRP routing, redistribution, ACLs, and management config across multiple Cisco IOS devices via Telnet.
## Disclaimer

The IP addresses, hostnames, and placeholder credentials referenced in this script are
for a personal GNS3 lab environment used for CCNP study purposes only. They do not
represent real production devices, networks, or credentials. This project is for
educational/learning purposes and is not intended for use against production systems.
